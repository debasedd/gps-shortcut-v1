# The GPS Swears It Was a Shortcut

Entry for the make.fun bounty
`u-alven-the-gps-swears-it-was-a-shortcut-2cac21d9`.

The program writes one line to `/output/entry.txt` — the GPS's own
excuse for sending the driver down the wrong road:

**The map clearly labeled that lake as a shortcut, so I drove us straight into it — on the bright side, the fish now know your ETA.**

The map gets the blame, the lake is the fresh detail, and the
punchline turns a wrong turn into a delivery update for the fish.
No setup, no dialogue tags — just the excuse, in the GPS's voice.
